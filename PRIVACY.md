# Sairo-Publisher privacy policy

Last updated: October 7, 2026

Sairo-Publisher ("the tool") is a private, internal tool used only by the
owner of the YouTube channel **sairo ch.** to upload that channel's own videos.
This policy explains what data the tool uses and how.

## YouTube API Services

The tool uses YouTube API Services. By using it, the channel owner agrees to be
bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms). Use of
Google data is also subject to the
[Google Privacy Policy](https://policies.google.com/privacy).

## Data the tool accesses

With the channel owner's permission, granted through Google OAuth, the tool
accesses:

- an OAuth access token and refresh token for the owner's Google account,
  limited to the YouTube scopes needed to upload and manage the channel's own
  videos;
- the channel's name, to confirm which channel it is signed in to;
- the channel's playlists, to add new videos to the right one;
- the videos it uploads and the details it sets on them (title, description,
  tags, category, language, privacy status, schedule, made-for-kids and
  synthetic-content declarations, thumbnail).

The tool does not access, collect or store data about any other YouTube user,
including viewers, commenters or subscribers.

## How the data is used and stored

- The data is used only to upload the owner's videos and set their details, at
  the owner's request.
- The OAuth token is stored only on the channel owner's own computer. It is not
  sent anywhere except to Google, when the tool calls the YouTube Data API.
- No data is sold, shared with, or disclosed to any third party.
- The tool uses no cookies, analytics or tracking.

## Keeping and deleting data

The token is kept until the owner deletes it or revokes access. Access can be
revoked at any time on the
[Google Account permissions page](https://myaccount.google.com/permissions).
Revoking access, or deleting the token file, stops the tool from using the
account. Videos it has uploaded remain on the channel, and the owner can manage
or delete them in YouTube Studio like any other video.

If this policy changes, the date above will be updated.
